# 光伏支架线模生成器（PV Support Line Model Generator）

用 Python（tkinter）做的光伏支架参数化建模辅助工具：通过图形界面输入组件、支架形式、构件截面、荷载等参数，自动生成支架线模，后续导出 DXF / 3D3S / SAP2000 供结构计算软件使用。

## 当前状态

- **版本**：V1.2.4（MVP 界面骨架，2026-08-12）
- 界面已完成：组件参数（含阵列功率）、支架形式侧面示意（缩放/平移/复位）、构件截面表（规格/型号/材质）、3D 线框转盘预览（Z 轴保持竖直）、荷载参数（含城市查表）
- 工程参数可保存/打开为 JSON
- **未完成**：M2 几何引擎（真实线模生成）、M3 导出（DXF/3D3S/SAP2000）、M4 正式截面库与荷载组合

## 运行

```bash
python pv_support_gui.py
```

要求：Python 3.10+（自带 tkinter），无需第三方依赖。

## 文件说明

| 文件 | 说明 |
|---|---|
| `pv_support_gui.py` | 主程序（界面骨架 V1.2.4） |

| `荷载规范城市数据.json` | GB50009-2012 附录 E.5 城市基本风压/雪压（34 省级、668 城市，50 年重现期） |

## 数据来源说明

`荷载规范城市数据.json` 取自《建筑结构荷载规范》GB50009-2012 附录 E.5 全国各城市雪压、风压值表（联网核对版）。光伏支架计算取 50 年重现期值（w50/s50）；个别冷门站点数值建议与正式规范文本复核。
